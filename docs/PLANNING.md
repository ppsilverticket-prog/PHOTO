# AI 사진 보정 앱 기획서 (가칭: PHOTO)

> EPIK · SNOW · SODA · Lightroom 급의 AI 보정 기능을 제공하는 Android/iOS 앱.
> 1차 목표는 **핵심 보정 기능의 완성도**, 2차 목표는 **구독/크레딧 결제 수익화**.

---

## 1. 제품 개요 & 포지셔닝

| 항목 | 내용 |
|---|---|
| 타깃 | 셀피/인물 사진 보정을 자주 하는 10~30대 + 감성 색감 보정 유저 |
| 핵심 가치 | "과하지 않은 자연스러운 AI 보정" + "터치 몇 번으로 끝나는 간편함" |
| 차별점 | 벤치마크 앱들의 강점 기능을 하나의 앱에서: AI 지우개(EPIK) + 자연스러운 피부 보정(SODA) + AI 프로필(SNOW) + 전문 색감 툴(Lightroom) |
| 수익 모델 | 구독(월/연) + 소모성 크레딧(고비용 생성형 AI 기능) 하이브리드 |

### 벤치마크 → 우리 기능 매핑

| 벤치마크 | 대표 기능 | 우리 앱에서의 구현 |
|---|---|---|
| EPIK | AI 지우개, 업스케일링, 얼굴/체형 보정 | Magic Eraser, AI 화질 개선, 얼굴 리터칭·체형 슬라이더 |
| SNOW | AI 프로필, 얼굴 인식 튜닝, 감성 필터 | AI 프로필 생성(서버), 얼굴 랜드마크 기반 자동 보정, 필터 스토어 |
| SODA | 자연스러운 피부 텍스처 보정 | 피부결 유지형 스무딩(주파수 분리 기반), 자연스러움 강도 슬라이더 |
| Lightroom | 색감 커브/HSL, Generative Remove | 프로 색보정 패널(커브·HSL·화이트밸런스), 생성형 개체 제거 |

## 2. 기능 정의

### 2.1 MVP (v0.1 — 기능 검증 단계, 결제 없음)

우선순위 순. **온디바이스로 가능한 것부터** 만들어 서버 비용 없이 기능을 검증한다.

1. **기본 편집기 셸**
   - 사진 불러오기(갤러리/카메라), 크롭/회전/미러, 실행취소(undo/redo) 히스토리, 원본 대비 보기(before/after), 저장/공유
2. **필터 & 색감 보정**
   - 프리셋 필터 20종(LUT 기반), 밝기/대비/채도/온도/틴트/하이라이트/섀도우 슬라이더
3. **얼굴 자동 인식 보정**
   - 얼굴 랜드마크 검출(MediaPipe Face Mesh) → 눈 크기/턱선/코/입 슬라이더 워핑
   - 자동 보정 원터치("자연스럽게 / 또렷하게" 프리셋)
4. **피부 보정 (SODA 스타일)**
   - 주파수 분리 기반 스무딩(피부결 유지), 잡티 제거 브러시, 톤 보정
5. **AI 지우개 (Magic Eraser)**
   - 브러시로 칠하면 개체 제거 — 온디바이스 LaMa 계열 인페인팅 모델
6. **AI 화질 개선 (업스케일링)**
   - Real-ESRGAN 계열 온디바이스 2x/4x 업스케일 + 얼굴 복원(GFPGAN 계열)

### 2.2 v1.0 (출시 버전 — 결제 도입)

7. **생성형 개체 제거(Generative Remove)** — 서버 디퓨전 인페인팅(고품질, 크레딧 차감)
8. **AI 프로필** — 셀피 10~20장 업로드 → 서버에서 LoRA 학습 → 스타일별 프로필 생성(크레딧)
9. **배경 제거/교체** — 세그멘테이션 + 배경 라이브러리
10. **체형 보정** — 다리 길이/허리/어깨 슬라이더(메시 워핑)
11. **필터 스토어 & 프리셋 저장** — 내 보정값을 프리셋으로 저장/재사용
12. **결제**: 구독(무제한 기본 기능 + 워터마크 제거 + 월 크레딧) / 크레딧 팩(생성형 기능용)

### 2.3 v2.0 이후 백로그

- AI 스티커/이모지 생성, 헤어스타일·메이크업 시뮬레이션, 영상 보정, 일괄(배치) 보정, 커뮤니티 프리셋 공유

### 2.4 무료 vs 유료 경계 (v1.0)

| 기능 | 무료 | 구독 | 크레딧 |
|---|---|---|---|
| 필터/색보정/크롭 | ✅ (필터 일부 잠금) | 전체 해금 | — |
| 얼굴/피부 보정 | ✅ (강도 제한 없음) | — | — |
| AI 지우개(온디바이스) | 일 3회 | 무제한 | — |
| 업스케일링 | 2x 일 3회 | 4x 무제한 | — |
| 생성형 제거(서버) | 체험 2회 | 월 50크레딧 포함 | 1회 = 1크레딧 |
| AI 프로필 | — | — | 1세트 = 50크레딧 |
| 저장 시 워터마크 | 있음 | 없음 | — |

> 원칙: **온디바이스(한계비용 0) 기능은 무료로 풀어 리텐션 확보**, GPU 서버 비용이 드는 기능만 크레딧 과금.

## 3. AI 기능별 기술 방안

| 기능 | 모델 후보 | 실행 위치 | 근거 |
|---|---|---|---|
| 얼굴 랜드마크 | MediaPipe Face Mesh (478pt) | 온디바이스 | 실시간, 무료, Android/iOS 공식 지원 |
| 피부 스무딩 | 전통 영상처리(주파수 분리 + bilateral) | 온디바이스 | 모델 불필요, 실시간 슬라이더 반응성 |
| AI 지우개 | LaMa (ONNX/TFLite 변환, ~50MB) | 온디바이스 | 중형 이미지에서 수 초 내 처리 가능 |
| 업스케일링 | Real-ESRGAN(x4, mobile 경량판) + GFPGAN(얼굴) | 온디바이스(2x) / 서버(4x 대형) | 큰 해상도는 모바일 메모리 한계 |
| 세그멘테이션(배경) | MediaPipe Selfie Segmentation / RMBG | 온디바이스 | 실시간 프리뷰 필요 |
| 생성형 제거/채우기 | SDXL-inpainting 또는 FLUX Fill (서버 GPU) | 서버 | 품질이 곧 과금 명분, 온디바이스 불가 수준 |
| AI 프로필 | SDXL + LoRA 학습(인물당 ~10분/GPU) | 서버(배치 큐) | 학습은 비동기 잡, 완료 푸시 알림 |

- 온디바이스 추론 런타임: **TFLite(+GPU delegate)** 또는 **ONNX Runtime Mobile**, iOS는 Core ML 변환 병행 검토.
- 서버 추론: GPU 인스턴스(예: L4/A10) + 잡 큐. 초기엔 Replicate/RunPod 같은 서버리스 GPU API로 시작해 트래픽 늘면 자체 호스팅 전환.

## 4. 기술 스택 & 아키텍처

### 4.1 클라이언트 — **Flutter 권장**

- 한 코드베이스로 Android/iOS 동시 출시(1인/소규모 팀에 최적).
- 이미지 편집 캔버스: 렌더링 성능이 필요하므로 필터/워핑은 **GPU 셰이더(Fragment Shader) 기반** 구현.
- 온디바이스 AI: `tflite_flutter` 또는 플랫폼 채널로 네이티브(NNAPI/Core ML) 호출.
- 대안: React Native(웹 인력 활용 시), 네이티브 2벌(성능 최우선이나 비용 2배). — 결정 필요 시 Flutter로 진행.

### 4.2 백엔드 (v1.0부터 본격 필요, MVP는 서버리스 최소 구성)

```
[Flutter 앱]
   ├─ 온디바이스 AI (TFLite/ONNX)          ← MVP는 여기까지로 서버 불필요
   └─ HTTPS
[API 서버 (FastAPI or NestJS)]
   ├─ Auth (소셜 로그인: Apple/Google/카카오)
   ├─ 크레딧 원장 + 구독 상태 (RevenueCat 웹훅 연동)
   ├─ 이미지 업로드 (S3 presigned URL, 원본 24h 자동삭제)
   └─ AI Job Queue (Redis) ──▶ [GPU 워커: 생성형 제거 / AI 프로필 학습]
                                     └─ 완료 시 푸시(FCM/APNs)
```

### 4.3 결제

- **RevenueCat** 채택 권장: App Store/Play 인앱결제 영수증 검증·구독 상태 관리·웹훅을 한 번에 처리, 초기 무료 티어 충분.
- 상품 구성: `월 구독`, `연 구독(할인)`, `크레딧 팩 3종(소/중/대)`.

### 4.4 프라이버시 (스토어 심사 핵심)

- 기본 보정은 전부 온디바이스 = "사진이 기기를 떠나지 않음"을 마케팅 포인트로.
- 서버 기능 사용 시 명시적 동의 + 원본 자동 삭제 정책 고지.
- 얼굴 데이터(AI 프로필 학습)는 학습 완료 후 즉시 파기 — 개인정보처리방침에 명시.

## 5. 프로젝트 구조 (제안)

```
PHOTO/
├── app/                    # Flutter 앱
│   ├── lib/
│   │   ├── features/
│   │   │   ├── editor/         # 편집 캔버스, undo/redo
│   │   │   ├── filters/        # LUT 필터, 색보정 슬라이더

│   │   │   ├── upscale/        # 화질 개선
│   │   │   └── paywall/        # 결제/구독 (v1.0)
│   │   ├── core/               # 이미지 파이프라인, AI 런타임 래퍼
│   │   └── shared/             # 디자인 시스템, 공통 위젯
│   └── assets/models/          # 번들 TFLite/ONNX 모델
├── server/                 # API 서버 (v1.0)
└── docs/                   # 기획/설계 문서
```

## 6. 개발 로드맵

| 단계 | 기간(예상) | 내용 | 완료 기준 |
|---|---|---|---|
| **M1** | 2주 | Flutter 셸 + 편집기 기본(불러오기/크롭/저장/undo) | 사진 열고 편집해 저장 가능 |
| **M2** | 2주 | 필터(LUT 20종) + 색보정 슬라이더(GPU 셰이더) | 60fps 프리뷰 |
| **M3** | 3주 | 얼굴 인식 보정 + 피부 보정 | 셀피 원터치 자동 보정 |
| **M4** | 3주 | AI 지우개 + 업스케일링(온디바이스) | 중형 사진 5초 내 처리 |
| **M5** | 2주 | 폴리싱 + 내부 테스트(TestFlight/내부 트랙) | MVP 배포 |
| **M6** | 4주 | 서버(생성형 제거·AI 프로필) + RevenueCat 결제 | v1.0 스토어 출시 |
