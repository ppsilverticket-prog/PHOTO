# 아이폰에서 웹 미리보기로 테스트하기

맥이 없어도 아이폰 사파리에서 앱을 바로 열어볼 수 있다.
푸시하면 GitHub Actions가 웹 버전을 빌드해 GitHub Pages에 올린다.

## 1. GitHub Pages 켜기 (최초 1회)

저장소 → **Settings** → 왼쪽 메뉴 **Pages** →
**Build and deployment**의 **Source**를 **GitHub Actions**로 바꾼다.

## 2. 배포 실행

`claude/ai-photo-editing-app-v94b4f` 브랜치에 푸시하면 자동으로 돈다.
수동으로 돌리려면 저장소 → **Actions** → **웹 미리보기 배포** →
**Run workflow**.

빌드는 3~5분쯤 걸린다. 완료되면 Actions 실행 화면의 `deploy` 작업에
접속 주소가 표시된다. 기본 주소는 다음과 같다.

```
https://ppsilverticket-prog.github.io/photo/
```

## 3. 아이폰에서 열기

사파리로 위 주소를 연다. 홈 화면에 추가하면 (공유 → 홈 화면에 추가)
주소창 없이 앱처럼 전체 화면으로 쓸 수 있다.

첫 접속은 파일이 커서 몇 초 걸린다. 와이파이를 권장한다.

## 웹에서 되는 것 / 안 되는 것

| 기능 | 웹 | 비고 |
|---|:--:|---|
| 사진 불러오기 | ✅ | 사진 보관함/파일에서 선택 |
| 자르기 · 회전 · 반전 | ✅ | |
| 실행취소 / 다시실행 | ✅ | |
| 필터 19종 + 강도 | ✅ | 썸네일 포함 |
| 색보정 7종 | ✅ | GPU 셰이더 실시간 |
| 원본 비교 (길게 누르기) | ✅ | |
| **피부결 · 피부톤 보정** | ✅ | 색상 마스크로 동작 |
| **눈 크기 · 얼굴 슬림 · 코 · 턱 · 입술** | ❌ | 아래 설명 |
| 저장 | ⚠️ | 갤러리 대신 브라우저 다운로드 |
| 공유 | ✅ | 공유 시트에서 "이미지 저장" 선택 가능 |

### 얼굴 워핑이 웹에서 안 되는 이유

얼굴 랜드마크 검출에 쓰는 **ML Kit이 Android/iOS 전용**이라 웹에 대응
구현이 없다. 웹에서는 얼굴이 0개로 잡히고, 랜드마크가 필요한 슬라이더
5종이 자동으로 비활성화된다.

반면 피부 보정은 얼굴 검출 없이도 **피부색(YCbCr) 마스크**만으로
동작하도록 설계해서 웹에서도 그대로 쓸 수 있다.

### 저장이 다르게 동작하는 이유

웹에는 사진 갤러리에 직접 쓰는 API가 없다. **저장** 버튼은 브라우저
다운로드로 대체된다. 사진 앱에 넣고 싶으면 **공유** 버튼을 쓰는 편이
낫다 — iOS 공유 시트에서 "이미지 저장"을 고를 수 있다.

## 성능에 대해

웹에는 진짜 백그라운드 격리(isolate)가 없어서, 자르기·회전·피부 보정처럼
CPU를 쓰는 작업이 도는 동안 화면이 잠깐 멈춘다. 네이티브 앱에서는
백그라운드에서 처리되므로 이 현상이 없다. **웹에서 느린 것이 곧 앱에서
느린 것은 아니다.**

반대로 필터와 색보정 슬라이더는 GPU 셰이더라 웹에서도 즉시 반응한다.
여기가 버벅인다면 실제 문제이므로 알려 달라.
